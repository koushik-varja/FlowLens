# Third-party dependencies

FlowLens source code in this repository is original project code. It uses third-party packages through their public APIs; no third-party repository is copied into this project.

Key Python dependencies: FastAPI, Uvicorn, Pydantic, SQLAlchemy, Alembic, NumPy, Pandas, scikit-learn, joblib, NetworkX, psycopg, pytest and HTTPX. Development quality tools declared: Ruff and mypy.

Frontend dependencies: React, React DOM, Vite, TypeScript, Vitest and ESLint-related packages.

PostgreSQL is used by Docker Compose. The sample event log is generated by `data/generator/generate.py` and is **synthetic**, not third-party company data.

Each dependency remains governed by its own license. Review the package metadata/lock state and licenses before redistribution in environments with additional compliance requirements.
